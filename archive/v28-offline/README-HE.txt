מנהלת ידע ואנרגיה – אגף ההנדסה, מועצה אזורית נווה מדבר
חבילת מקור, ידע ונתונים של גרסה 28 | 22.11.2026

התחלה
חלצו את ה־ZIP לתיקייה מקומית. לעיון מהיר פתחו את START-HERE.html בדפדפן. דף זה קורא נתונים הכלולים בקובץ עצמו ואינו דורש התקנה, חשבון או אינטרנט. לכל רשומה אפשר לפתוח את כל השדות המקוריים. ליד מאגרי הנתונים מופיע גם קישור לקובץ הגולמי.

הפעלת היישום המלא
ב־Windows x64 לחצו פעמיים על START-WINDOWS.cmd. החבילה כוללת Node.js 24.22.3 ל־Windows x64, את רכיבי המפה ואת היישום הבנוי. אין צורך ב־npm install, ב־Cloudflare, ב־GitHub או בחשבון ChatGPT.
ב־macOS/Linux או בארכיטקטורה אחרת עם Node.js 24 מתאים שכבר מותקן, מריצים מתיקיית החבילה: node offline/start.mjs
המערכת מאזינה ב־127.0.0.1 בלבד. לפתיחה הראשונה השתמשו בכתובת setup שמופיעה בחלון ובקוד ההקמה המקומי. בחרו מייל וסיסמה מקומיים ושמרו את קוד השחזור המוצג פעם אחת. קוד האורח המקומי הראשוני מופיע באותו חלון. בהפעלות הבאות המערכת משתמשת בחשבון המקומי. כדי לסיים סוגרים את חלון ההפעלה או מקישים Ctrl+C.
הגדרות, פרויקטים והערות חדשים שתוסיפו בעותק המלא נשמרים בתיקיית local-state, שנוצרת בהפעלה הראשונה. לשמירת עבודתכם, גבו את התיקייה אחרי סגירת היישום.

מה כלול
project/ – כל קובצי המקור של הגרסה שפורסמה, קוד השרת והדפדפן, רכיבים, חישובים, בדיקות, הגדרות דוגמה, סכמות ומיגרציות, תוצר השרת וקובצי הכניסה של GitHub Pages. קובצי ממשק הידע שנוצרו בזמן הבנייה צורפו גם בפורמט פתוח בתיקיית web.
project/web/ – מוסדות, מתקני ספורט, גבולות ותוכניות. ב־web/energy נמצאים נתוני גגות וקירוי, בדיקות הרשת, טבלאות CSV, תמונות ותיעוד לנכסים.
project/components/solar-models/ – מודלים עסקיים ותכני האסדרה, האגירה והחיבור לרשת.
project/sources/ – ארכיון יצוא GovMap המקורי, ראיות שיוך, תצלומים, מטא־דאטה ותשובות רשמיות שמורות, תאריכי שליפה, מקורות ומתודולוגיה.
reference-documents/ – עותקי PDF מקישורים מפורשים שקיימים במערכת ומפתח URL מול קובץ מקומי. הורדו המסמכים המקושרים עצמם, ללא חיפוש עדכונים או החלפת ערכי החישוב באתר. הגרסה במקור המקושר עשויה להשתנות עם הזמן.
snapshot/ – מסד SQLite עם סכמת המערכת, יצוא JSON של טבלאות התוכן ומלאי הגרסה. בבדיקת המסד בענן לא נמצאו פרויקטים, הערות, שינויים ידניים במיקומים, קובצי ייבוא בטיפול, סבבי סנכרון, תוצאות סנכרון חדשות או הגדרות חיבור חיצוניות. הנתונים המקצועיים הקיימים נטענים מקובצי האתר. סודות, סיסמאות, קודי שחזור והפעלות של משתמשי האתר המקוון אינם מועתקים. פריטים שנשמרו רק באחסון המקומי של הדפדפן של משתמש אינם חלק מהמסד המרכזי.
offline/ – תוכנית ההפעלה המקומית והספריות המצורפות. SHA256SUMS.txt מאפשר אימות של הקבצים לאחר החילוץ.

עבודה בלי רשת
המחשבון, השכבות המקומיות, תכני הידע והאסמכתאות השמורות זמינים מהעותק. מפת הרחובות המקוונת אינה מופעלת. פעולות שמטרתן להוריד עדכונים מהרשת ממתינות לשימוש בגרסה המקוונת. הפניות לדפי אינטרנט, מפות חיות ואתרים שלא נשמרו בקבצים נשארות קישורי ייחוס. חלק מתצלומי המקור והראיות כוללים כתובות מקור היסטוריות. ערכים חסרים והסתייגויות נשמרו כפי שהופיעו בגרסה זו.

מסד ידע מרוכז למפתח או לאנליסט
snapshot/energy-knowledge.sqlite מרכז את סדרות הנתונים המקומיות בפורמט SQLite, כולל טבלאות המקור, CSV, שכבות GIS וקובצי הידע המובנים. טבלת datasets מקשרת כל סדרה לקובץ המקורי. records שומרת את תוכן הרשומה ב־JSON ואת מיקומה בסדרה. לדוגמה:
SELECT json_extract(row_json, '$.name') AS roof_name, json_extract(row_json, '$.potential_kw') AS potential_kw FROM roofs;
SELECT json_extract(row_json, '$.SHEM_MOSAD') AS institution FROM institutions;
הטבלאות יכולות להכיל רמות מידע שונות וחופפות. אין לחבר את מספרי הרשומות מכל הסדרות כדי לחשב מספר נכסים ייחודיים.
